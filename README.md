# PetAdopt - Pet Adoption Platform

Hey there! This is my Pet Adoption Platform project made with React, Tailwind CSS, Express, and MongoDB. 

## Live Link
- Live Web Site: https://pet-adoption-rinku-a9.netlify.app
- Live Server API: https://pet-adoption-server-pied.vercel.app

## What is the purpose of this project?
The main goal of this project is to make adoption easier for pets. People can view pets like cats, dogs, and birds, and make requests to adopt them. Also, pet owners can list their pets for adoption and manage requests they receive from other users.

## Cool Features of this project
- **User Authentication**: Log in using email/password or your Google account. Firebase handles the auth!
- **Search & Filter**: Search pets by their name or filter them by category (Cat, Dog, Rabbit, Bird) on the All Pets page.
- **Easy Adoption Flow**: Fill up a quick form with pickup date and message to request adoption. Pet owners can't request their own pets!
- **User Dashboard**: A dedicated dashboard area to add pets, see your listings, and track your adoption requests.
- **Requests Approval Modal**: Manage requests easily! Approve or reject requests right from your listings table with a clean modal.
- **Dark/Light Mode**: Toggle between dark and light themes using the switcher button in the navbar.
- **Mobile Friendly**: The website is fully responsive and looks good on phones, tablets, and desktops.
